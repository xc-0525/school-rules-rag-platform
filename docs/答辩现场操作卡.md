> 打印或存手机。答辩前 30 分钟开始照做，不要在开场前 5 分钟才启动。

| 时间点 | 动作 |
| --- | --- |

## 二、启动顺序（严格按序，缺一步都不行）

**① 确认 MySQL 在跑**（Windows 服务，通常开机自启）

```powershell
Get-Service MySQL* | Select-Object Name, Status
```

不是 `Running` 就 `Start-Service <名字>`。

**② 起 Neo4j（单独开一个 PowerShell 窗口，全程保持打开）**

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_neo4j.ps1
```

看到 `Started` 后，浏览器能打开 <http://127.0.0.1:7474> 就说明活了。

> ⚠️ 这个窗口**不能关**。关了图检索就没了，双路召回变单路，演示效果打对折。

**③ 起后端（再开一个窗口）**

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend.ps1
```

**必须等到这个信号**（约 2–3 分钟，BGE 模型加载）：

```bash
curl http://127.0.0.1:8000/health
# 看到 "vector_ready": true 才行，false 就是还没加载完，继续等
```

**④ 打开 <http://127.0.0.1:8000>**

`SERVE_FRONTEND=1` 已在前端 dist 挂到后端，不需要另起 Vite。
登录：`admin` / `admin123`（管理员，可演示文档管理）；`student` 可演示学生视角。

## 四、故障预案（按这个顺序降级）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `vector_ready` 一直 `false` | 模型路径失效 | 检查 `G:\ai-models\hf\hub\models--BAAI--bge-small-zh-v1.5\...` 是否存在 |
| Neo4j 起不来（Java/端口） | 7687 被占用或 Java 环境变了 | 重启电脑再试；仍不行 → 下面「降级 A」 |
| 8000 端口被占用 | 上次的后端没退干净 | `start_backend.ps1 -Port 8001` |
| 问答报「模型不可用」 | DeepSeek Key 失效/欠费 | 提前一天确认余额；现场可讲「降级落库」设计（答案失败但记录仍存） |
| 整个后端起不来 | 环境炸了 | 下面「降级 B」 |

**降级 A：关图检索，保向量**

```powershell
$env:GRAPH_MODE='mock'
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend.ps1
```

代价：recall@3 从 0.85 降到 0.80（你自己的消融实验数据），演示可接受。**话术**：「图谱服务临时不可用，系统自动降级为纯向量检索，召回率下降 5 个百分点」——这反而证明你设计了降级路径。

**降级 B：极简版兜底（零数据库）**

```powershell
cd backend
& 'G:\DevEnv\Python\Python314\python.exe' -m uvicorn main:app --port 8000
```

单文件 MVP，Mock 双 Agent + DeepSeek 流式，40 项冒烟检查通过。功能少但保证能讲。

**降级 C：完全断网**

```powershell
cd backend
$env:LLM_MODE='mock'
& 'G:\DevEnv\Python\Python314\python.exe' -m uvicorn app.main:app --port 8000
```

Mock 模式秒起，讲架构和代码，不演示真实生成。
